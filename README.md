# PostgreSQL query exercises

A collection of SQL and PL/pgSQL exercises from School 21. The repository contains individual query solutions, database setup scripts and the original exercise descriptions.

## Explore the work

| Section | Contents |
|---|---|

| [Team 01](SQL_Team_01/) | Data-warehouse and query exercises |

For a starting point, inspect [query solutions](SQL_01/src/) and [database-function exercises](SQL_09/src/).

## Running an exercise

Use an isolated PostgreSQL development database. Read the exercise's own README and setup SQL before running its solution files; datasets and prerequisites differ between sections.

Some exercises create or modify database objects and data. Do not run the scripts against a production database.

## Scope

This is a learning collection rather than an application or a production data platform. It shows SQL practice alongside the application and systems projects in my portfolio. Original exercise documentation is preserved in each section.
